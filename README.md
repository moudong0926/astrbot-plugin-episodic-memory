# 情景记忆（Episodic Memory）

给 AstrBot 的**长期记忆**插件：让机器人记住聊过的事、记住你是谁、记住你们的约定，并且**随着时间自然遗忘**。

> **一句话**：摘要做索引，细节做外挂，权限做隔离，时间做衰减，转生带前世。

---

## ✨ 核心特性

### 1. 五层记忆流水线

| 层 | 作用 |
|---|---|
| **触发层** | 5 种触发：显式指令 / 话题终结 / 5 分钟无消息 / 4 轮兜底 / 转生前兜底 |
| **过滤层** | 纯闲聊、太短、无信息量 → 直接丢弃，**不浪费 API** |
| **提炼层** | LLM 输出结构卡片：`type`（事实/偏好/规则/情绪）+ `confidence` + `important` |
| **归档层** | 向量去重（相似 ≥0.85 合并）+ 90 天自动归档 |
| **注入层** | 向量召回 → 重排 → Top-3 → **2000 字硬预算** |

### 2. 摘要做索引，细节做外挂

```
cards 表  = 摘要 + 元数据 + 向量（索引，轻）
facts 表  = 具体细节（外挂，重，按需展开）
```

**不存原文，存提炼后的摘要**——这是节省 token 的根本。

### 3. 卡片所有权与隐私

- 每张卡片有主人：`owner_id`（QQ）+ `owner_name`（昵称）；
- 只能改自己的卡片；管理员可改所有人；**没人能改管理员的**；
- **防伪装**：实体里出现别人的 QQ 号 → 拦截；
- **私聊隔离**：`scope='private'` 的卡片，群里任何人都检索不到。

### 4. 遗忘机制（像人脑）

```
最终分 = 0.7 × 语义相似度
       + 0.2 × 时间新鲜度（90 天衰减）
       + 0.1 × 使用频率（命中次数）
```

- 90 天未用 + 命中 < 3 次 + 非重要 → **归档**（不删，只是不再被检索）；
- `important=true` 的卡片**永不归档**；
- 像人脑：“想不起来” ≠ “彻底消失”。

### 5. 转生（上下文管理）

```
对话 token ≥ 阈值（默认 32K）
  ↓
① 兜底提炼剩余的 pending
  ↓
② 开新会话（清对话历史）
  ↓
③ 灵魂记忆 + 记忆卡片重新注入
```

**前世记忆带进转世**——对话没了，记忆还在。

### 6. 类型系统

| type | 含义 | 例子 |
|---|---|---|
| `fact` | 客观事实 | “东的 QQ 是 1705007522” |
| `preference` | 偏好 | “东爱吃鱼” |
| `rule` | **行为规则** | “以后别叫我全名” |
| `emotion` | 情绪状态 | “东今天很烦” |

LLM 判类型 → 不明确时用关键词兜底 → 默认 `fact`。

## 📦 安装

### 方式一：插件市场（推荐）

在 AstrBot WebUI → 插件市场 → 搜索「情景记忆」→ 安装。

### 方式二：手动安装

1. 下载 zip 解压到 `AstrBot/data/plugins/asterbot_plugin_episodic_memory/`
2. 重启 AstrBot
3. 填写配置（见下方）

### 依赖

| 版本 | 依赖 |
|---|---|
| **完整版** | `sentence-transformers` + `torch`（约 2GB，用于 bge 重排）|
| **轻量版** | **零额外依赖**（重排用规则，不开销） |

## ⚙️ 配置

在 AstrBot WebUI → 插件 → 情景记忆 → 配置：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| **`embed_key`** | 空 | **必填**：智谱 API key（免费申请）|
| `embed_url` | `https://open.bigmodel.cn/api/paas/v4/embeddings` | 向量 API 地址 |
| `embed_model` | `embedding-3` | 向量模型（2048 维）|
| `context_token_limit` | `32000` | 上下文转生阈值 |
| `extract_enabled` | `true` | 是否自动提炼 |
| `extract_every_n` | `4` | 兜底触发轮数 |
| `session_gap_minutes` | `30` | 会话间隔（分钟）|
| `recall_top_k` | `5` | 检索召回数 |
| `soul_recent_cards` | `5` | 新会话注入的最近卡片数 |
| `time_decay_days` | `90` | 时间衰减天数 |
| `w_score_semantic` | `0.7` | 语义权重 |
| `w_score_time` | `0.2` | 时间权重 |
| `w_score_hit` | `0.1` | 命中权重 |

### 获取智谱 API Key

1. 注册 [智谱开放平台](https://open.bigmodel.cn)
2. 创建 API Key
3. 填入 `embed_key`
4. `embedding-3` **免费额度足够个人使用**（几千张卡片）

## 🚀 使用

### 自动运行

装上就自动工作，**不需要你做什么**：
- 聊天时自动收集对话；
- 满足触发条件时自动提炼；
- 每轮自动检索并注入相关记忆。

### 手动工具

机器人可以调用以下工具：

| 工具 | 用途 |
|---|---|
| `memory_note` | 手动记录一条记忆 |
| `memory_recall` | 检索相关记忆 |
| `memory_detail` | 查看某张卡片的详情 |
| `memory_forget` | 删除某张卡片 |
| `memory_soul` | 读取/写入灵魂记忆 |

### 在聊天里使用

```
用户：记住，我下周要出差
机器人：（自动触发提炼，存入卡片）

用户：你还记得我下周要干嘛吗
机器人：（自动检索，回答"出差"）
```

## 🏗️ 架构图

```
消息 → pending
  ↓
① 触发层（5 条，任一命中）
  ↓
② 过滤层（纯闲聊 → 丢弃）
  ↓
③ 提炼层（LLM 输出结构化卡片）
  ↓
④ 归档层（向量去重 + 90天归档）
  ↓
⑤ 落库（cards + facts）

──────────── 读取 ────────────

用户发消息
  ↓
向量检索 Top-10
  ↓
bge 重排 → Top-3（轻量版用规则）
  ↓
2000 字预算
  ↓
注入 system_prompt
  ↓
LLM 生成回答
```

## ❓ 常见问题

### Q1：会不会很耗 token？

**不会**。
- 记忆注入 ≤2000 字符（约 1000 token）；
- 只占上下文 3%；
- 过滤层拦掉 30%~50% 的无效提炼。

### Q2：记忆会不会越来越多？

**不会无限膨胀**。
- 90 天自动归档；
- `important` 卡片永不归档；
- 归档 ≠ 删除，仍可手动调出。

### Q3：她和别人聊天，会泄露我的隐私吗？

**不会**。
- 私聊记忆 `scope='private'`；
- 群里任何人（包括其他群友）都检索不到；
- 只有管理员能看。

### Q4：重启后记忆会丢吗？

**不会**。
- 记忆存在 `data/memory.db`（SQLite）；
- 重启后自动加载；
- 备份 = 复制 `memory.db`。

### Q5：转生是什么意思？

对话 token 到阈值（默认 32K）时：
1. 把没提炼的对话再提炼一次；
2. 开新会话（清空对话历史）；
3. 灵魂 + 记忆卡片重新注入。

**对话没了，记忆还在。**

### Q6：支持多机器人吗？

**单实例**。每个 AstrBot 实例独立一个 `memory.db`。

### Q7：能迁移到别的机器吗？

**能**。复制整个插件目录（含 `data/`）即可。
